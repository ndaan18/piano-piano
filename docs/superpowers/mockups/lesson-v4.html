Lime is the hero, never the text. It's a fill: buttons, highlighter, progress, "giusto". Black on lime has ~17:1 contrast, so it's always readable. Lime as text on paper would disappear, so it's never used that way.

The partners sit opposite lime on the colour wheel. Lime is roughly 75°, so ultramarine and lilac (its complement and split-complement) make it vibrate. Pink and cyan add the moodboard's heat and air. Orange is used only for mistakes.

Colour carries meaning. Rosa = informale (tu), warm and close. Oltremare = formale (Lei), cool and polite. After a week you'll read register by colour without thinking.

One mood per unit. Each cover blends lime with one partner (lime + pink, lime + cyan, lime + lilac…) into the grey surface. Grain sits only on the cover blur, so it looks printed while the UI stays crisp.
